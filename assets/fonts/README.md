# Bundled typography

Manrope (body) and Space Grotesk (headings and metrics), Latin variable WOFF2 subsets from Google Fonts. Embedded by build_panel.py, with no runtime font CDN requests. Other scripts use system fallbacks.

Sources: https://fonts.google.com/specimen/Manrope and https://fonts.google.com/specimen/Space+Grotesk

Both fonts are distributed under the SIL Open Font License; see the included OFL files.
