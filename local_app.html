WireGuard network tuner

Tests your PC's connection using the official Xray core. It creates temporary local proxies, without installing a tunnel or changing Windows proxy settings.

1. Import a client

Choose a WireGuard .conf, Xray JSON, or paste a wireguard:// link. Keys stay on this PC. Temporary core configs are removed after each trial.

2. Test the imported WireGuard client

Baseline checks are separate: a working direct connection or current v2rayN proxy does not mean the imported WireGuard client works. That proxy can be using a completely different profile.

Before full testing: stop other apps using this client's keys, or create a separate test client in your VPS panel. Two active apps using one peer can disrupt each other.

Full scan: MTU 1280 / 1360 / 1420 plus your imported MTU when different, and Cloudflare / Google / Quad9 DNS, using up to about 6 MB of downloads. Keepalive stays at 25 seconds and is not benchmarked. Tests may take several minutes if connections time out.

If nothing connects

MTU and DNS presets cannot repair incorrect keys, server NAT/forwarding, a blocked UDP port, or ISP filtering. Open the VPS panel's Connection diagnostics. In v2rayN, activate the profile and enable system proxy or TUN. New JSON exports accept HTTP and SOCKS on mixed port 127.0.0.1:10808, plus HTTP on 10809.
