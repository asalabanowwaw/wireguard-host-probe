Low MTU: custom values 576-1420 are supported. Below 1280, native WireGuard exports are IPv4-only and do not capture IPv6: IPv6 traffic may bypass the VPN. Use only with IPv6 disabled or blocked on the device if full traffic protection is required. Xray JSON exports continue to block IPv6. Lower MTU does not fix every connection stall.

Connection diagnostics

Check server forwarding, NAT, firewall rules and internet access when clients connect but websites do not load.

Using v2rayN

Use a current Xray core. Import the WireGuard link, activate the profile, and enable system proxy or TUN. Use Global routing temporarily while troubleshooting. The JSON export accepts HTTP and SOCKS on 127.0.0.1:10808, plus HTTP on 10809. These are local client ports; the panel itself is hosted on your VPS.

If larger transfers stall, try the v2rayN compatibility export, which uses MTU 1280 and Cloudflare DNS without changing the saved client. A handshake does not prove server internet forwarding is working.

PC network tuner

Run the companion app on your PC at http://127.0.0.1:8788 to test MTU and DNS through real WireGuard connections. This is a separate local tool; this VPS panel stays on your public VPS address.

Download the project and run setup-local.ps1, then Start local tuner.cmd. After successful trials, export a preset file and import it here.

Clients

Create a separate client for each device, including when using different apps.

v2rayN / v2rayNG: copy a WireGuard link and import it from the clipboard in a current version. Or download Xray JSON and import it as a custom configuration using the Xray core. Share links may not retain keepalive; the JSON export does. These exports still use WireGuard on the network.

Saved presets

Save connection and DNS settings, then select them under any client's Network profile. Save the same name to edit a preset. Editing or deleting a preset does not change settings already applied to clients.

Connection settings

Changes apply to newly downloaded configs. Download and import them again on your devices. The advertised port must reach the server's listening port through your firewall or port mapping.

Project updates

Updates preserve server keys, clients, presets and settings. The panel restarts briefly. Refresh after about 30 seconds. For progress, run journalctl -u 'wg-auto-update-*' -n 50 over SSH.

IPv4 internet VPN. IPv6 traffic is captured or blocked by exported configurations; IPv6 internet is not provided.
