CLIENT HELP

Connected, but nothing loads?

  1. Run one app per client key. Sharing keys across active devices can switch the peer endpoint.
  2. With WireSock, clear a leftover v2rayN system proxy so your browser uses the intended path.
  3. Try MTU 1280 before changing several settings at once.
  4. Check the public exit IP in the affected app. A handshake alone does not confirm internet forwarding.

v2rayN JSON uses current Xray's mixed HTTP/SOCKS port 10808, plus HTTP port 10809. Share-link imports may omit keepalive settings.
